**# PLP Python Week 5 Assignment**



**## Assignment: Password Generator \& Your Own Module**



**This assignment practices Python modules, random password generation, functions, and importing a custom module.**



**## Files Included**



**- `password\_generator.py` - Generates random passwords of 8 and 12 characters using the `random` and `string` modules.**

**- `helpers.py` - Contains the `tables\_needed()` and `welcome()` functions and uses the `math` module.**

**- `main.py` - Imports `helpers` and displays the required output.**



**## How to Run the Programs**



**Run the password generator:**



**```bash**

**python password\_generator.py**

**```**



**Run the main program:**



**```bash**

**python main.py**

**```**



**Run the helpers module independently:**



**```bash**

**python helpers.py**

**```**



**## Expected Output**



**Running `main.py`:**



**```text**

**Welcome to PLP, Amina!**

**8**

**4**

**```**



**Running `helpers.py`:**



**```text**

**3**

**```**
